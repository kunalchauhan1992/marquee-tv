# Acer AR50QDXGU2875AT 50" QLED Google TV (MOKA R10G board, Realtek RT2875P, about 2 GB RAM), India
# Android 14 / SDK 34, build UKR1.260612.001. Tested on two sets of the same model, October 2026.
#
# Everything here is DISABLED for user 0 (pm disable-user), never uninstalled.
# Apply:  .\scripts\apply-debloat.ps1 -TvHost <tv ip> -List examples\acer-r10g\debloat.txt
#         (runs cleanyourtv's tools\disable.ps1 with its safety checks, then restricts reenabled-at-boot.txt)
# Undo:   .\scripts\restore.ps1 -TvHost <tv ip> -List examples\acer-r10g\debloat.txt
#
# [boot] = Acer's firmware enables it again at every cold boot (a factory check you can't change without root).
# Those also go in reenabled-at-boot.txt: apply-debloat.ps1 blocks them from running in the background, which
# does survive a reboot, and Marquee hides them from its Apps page.
#
# Kept on purpose (do NOT add these):
#   com.google.android.apps.tv.launcherx      stock Home; Marquee takes the Home button with an accessibility service
#   com.google.android.tungsten.setupwraith   owns the saved Wi-Fi network on this platform: disabling it drops Wi-Fi + ADB
#   com.realtek.tv, .tv.passthrough, .dtv, .tv.atv, .dtmb, .tv.isdb, .tv.atsc   HDMI inputs and tuner (TV input services)
#   com.apps.mk.sk, com.apps.fivekey, com.apps.virtualkey, com.realtek.globalkeyhandler, com.apps.bluetoothremote   remote keys
#   com.apps.ota, com.apps.authota, com.realsil.ota   firmware updates
#   com.apps.tvmanager                        "TV Manager" (the owner uses it)
#   Play Store, Play Services, Gboard, Assistant (katniss), Chromecast (mediashell), Android ad services
#   com.apps.factory.ui                       factory menu: never start it, never disable it
#
# Ask the owner first about the "choices" batch: casting receivers, YouTube Music, VLC, USB player.
